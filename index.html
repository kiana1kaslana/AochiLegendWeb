伤害结算管线 —— 一个伤害从打出去到落地，依次经过这些判定

出手方按顺序结算；受击方按顺序判定，任意一步「闪避」成功则后续全部跳过。
① 选敌（同排前排优先 / 【群攻】随机 n 个 / 指定最低血等）→ ② 气势倍率（大招：气势/100）→ ③ 倍率 × 攻击→ ④ 连击 / 追击 / 溅射分段→ ⑤ 闪避判定→ ⑥ 暴击判定（基础 20% / 150%）→ ⑦ 元素克制→ ⑧ 防御减免→ ⑨ 穿透→ ⑩ 格挡→ ⑪ 护盾 / 减伤→ ⑫ 状态附加（含【控制】）→ ⑬ 吸血回收→ ⑭ 反击
旁路：【毁灭伤害】= 真实伤害（在 ①~⑭ 全部走完之后才结算）→ 直接扣血，跳过 ⑦ 克制 / ⑧ 防御 / ⑨ 穿透 / ⑩ 格挡 / ⑪ 护盾减伤
中毒 / 灼烧 / 流血这类持续伤害，现在也统一按【毁灭伤害】度量 —— 不吃防御、减伤和护盾，谁的毒都一样疼。
【毁灭伤害】挑目标的时机是「主体伤害结算完那一刻」，而且只挑存活单位 —— 所以「对血量最低单位造成毁灭伤害」是补刀语义：先把人打残，再补掉剩下的那个血最少的。
【群攻】*n：一批目标同时挨打→ 随机挑 n 个敌方目标，伤害一起结算，回放里整组一帧播完，被点名的格子血条同时下降
【连击】*n：再给 n-1 个出手回合→ 每个额外回合按当时气势重新决定：够门槛就再放一次大招，不够就自动执行一次平a并回气势 +50。回放里逐次播放，伤害一个一个往下跳

四大职业 —— 角色定位速查

特殊职业 —— 叠加在基础职业之上的第二层

特殊职业不替代基础职业：属性成长曲线、推荐站位仍然由基础职业决定，特殊职业额外挂一层专属机制。 目前只有【英雄】一种，它的机制是「英雄技」——进入战斗前结算的全队光环。

角色自定义设计器 —— 从零捏一个角色，或者改已经有的（在「角色仓库」里点「✎ 编辑此角色」载入）。定基础属性（HP/攻/防/速/元素）+ 选 1 个普攻 + 1 个大招 + 任意被动。词条数值/概率/回合/目标都自己填，改完点保存，改动会存在浏览器里。

想单独调数值不想动整套技能，也可以走「技能词条」页。
⚠ 技能是共享的：两个角色用了同一个技能时，改词条两边一起变。保存前先看技能块上标着「被 N 个角色共用」。
